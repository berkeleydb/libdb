## SQLite Interface Upgrade

Berkeley DB's SQL interface includes code from SQLite. The version of SQLite used has been upgraded, so DB SQL is compatible with SQLite version 3.7.6.2. Please see the release notes at <a href="http://sqlite.org/changes.html" class="ulink" target="_top">http://sqlite.org/changes.html</a> for further information.
