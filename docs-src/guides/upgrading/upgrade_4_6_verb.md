## DB_VERB_REPLICATION

The <a href="../../api/c/envset_verbose.md#set_verbose_DB_VERB_REPLICATION" class="olink">DB_VERB_REPLICATION</a> flag no longer requires the Berkeley DB library be built with the --enable-diagnostic configuration option to output additional replication logging information.
