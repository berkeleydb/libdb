## operator=

### Function Details

``` c
const self& operator=(const self &itr)
 
```

Assignment operator.

This iterator will point to the same key/data pair as itr, and have the same configurations as itr.

#### Parameters

##### itr

The right value of assignment.

#### Return Value

The reference of itr.
