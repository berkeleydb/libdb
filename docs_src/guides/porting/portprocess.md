## Berkeley DB Porting Process

As with any porting project, porting Berkeley DB to a new platform consists of the following process:

1.  Determine the modifications that you need to make in the base code and create a working executable of Berkeley DB on the target platform as described in <a href="newbinary.md" class="xref" title="Chapter 2. Creating a New Berkeley DB Binary">Creating a New Berkeley DB Binary</a>.

2.  Perform final test and quality assurance functions on the target platform as described in <a href="testport.md" class="xref" title="Chapter 3. Testing and Certifying the Port">Testing and Certifying the Port</a>.
