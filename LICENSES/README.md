# LICENSES

Per-component license texts for third-party code and formats that Berkeley DB
(libdb) ships or interoperates with. The primary project license is the
top-level [`LICENSE`](../LICENSE); these are the additional/component licenses
that also apply.

| File | Applies to |
|------|-----------|
| `license_db.html` | The Berkeley DB (Sleepycat/Oracle) license, HTML form (same terms as the top-level `LICENSE`). |
| `BSD.txt` | Regents of the University of California BSD license (original 4.4BSD DB code). |
| `HARVARD.txt` | Harvard University copyright (historical DB lineage). |
| `SPL.txt` | Oracle Sleepycat Public License notice. |
| `CDDL.txt` | Common Development and Distribution License (bundled SQL/JDBC components). |
| `ASM.txt` | ASM bytecode framework (bundled with the Java bindings). |

Relocated from the old `docs/legal/` and `docs/license/` when the scraped
Oracle DocBook archive was removed from `master` (that archive is preserved on
the `gh-pages` branch under `docs/db/`).
