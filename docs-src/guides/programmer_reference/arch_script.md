### Perl

Two Perl wrappers are distributed with the Berkeley DB release. The Perl interface to Berkeley DB version 1.85 is called DB_File. The Perl interface to Berkeley DB version 2 and later is called BerkeleyDB. See <a href="ext_perl.md" class="xref" title="Using Berkeley DB with Perl">Using Berkeley DB with Perl</a> for more information.

### PHP

A PHP wrapper is distributed with the Berkeley DB release. See <a href="ext_php.md" class="xref" title="Using Berkeley DB with PHP">Using Berkeley DB with PHP</a> for more information.

### Tcl

A Tcl wrapper is distributed with the Berkeley DB release. See <a href="tcl.md#tcl_intro" class="xref" title="Loading Berkeley DB with Tcl">Loading Berkeley DB with Tcl</a> for more information.
