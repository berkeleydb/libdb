## close_db_cursors

### Function Details

``` c
 size_t close_db_cursors(Db *dbp1)
 
```

Close cursors opened in dbp1.

#### Parameters

##### dbp1

The database handle whose active cursors to close.

#### Return Value

The number of cursors closed by this call.
